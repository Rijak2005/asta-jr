A simple Discord.js bot to help me manage my discord server: Professor Astatine's class
The bot can perform the following functions:
  - kick people
  - generate photos of food
  - play jokes on a voice channel
  - track stats like my youtube channel subscribers, server members, etc.
  - welcome users to the server
  - assign roles based on reactions
  - work with other bots to implement a currency system within the server
